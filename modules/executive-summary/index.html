# MJSovereign A responsive static website for the National Workforce Grid for Responsible Leadership and Technological Empowerment in Bangladesh. ## Project structure - `index.html` — main landing page - `sitemap.html` — tree-based navigation and project map - `modules/` — major project modules - `modules/executive-summary/` - `modules/geographic-control-system/` - `modules/technology-validity-security/` - `modules/structure-analytics/` - `DGD/` — protected dashboard - `css/style.css` — shared styling - `js/script.js` — navigation and interaction logic - `js/i18n.js` — EN | BN bilingual content switching ## Features - Modern landing page redesign - EN / BN language toggle - Infinite tree-based site map - Structured project modules for ongoing development - Scalable static site layout suitable for GitHub Pages ## Local development ```bash python -m http.server 8000 ``` Then open: - http://localhost:8000/ - http://localhost:8000/sitemap.html - http://localhost:8000/DGD/index.html ## DGD access The protected dashboard uses the following password: ```text 23542 ``` ## Deployment This project can be published to GitHub Pages, Netlify, Vercel, or any static hosting provider.
